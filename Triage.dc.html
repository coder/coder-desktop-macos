The search box only knows titles
filteredSessions lowercases the query and matches it against $0.title over the rows already in memory. Titles are model-generated, so they rarely contain the words a person actually remembers — a file name, an error string, a branch. Archived chats aren’t searched at all, because they aren’t loaded.

What to build
1
Keep the instant local title filter as the first pass — it costs nothing and covers the common case.
2
Debounce ~250 ms, then ask the server for search:<query> and append an “In messages” group with the matching snippet. Archived chats surface here with their badge.
3
Bind ⌘F to focus the field, ↓ to walk results, ↵ to open. Note the server’s caveat inline when a query returns nothing: message content is indexed periodically, so a chat from a minute ago may not be searchable yet.
4
Go past the web here. Donate each chat to Core Spotlight (CSSearchableItem: title, turn summary, workspace) so ⌘Space finds a chat from anywhere in macOS and opens it deep-linked — the app already links CoreSpotlight, it just donates nothing. Pair it with a ⌘K palette inside the window for chats, workspaces and actions in one field.
