Finding & proposed change
Flow
01
Search only matches titles — use the server’s full-text search
Titles are auto-generated, so the words a user remembers (“the flake in the auth test”) are in the transcript, not the title. Send the query as chats?q=search:… and merge results into the sidebar, keeping the local title filter as the instant first pass.
Triage
02
An empty picker is invisible, not explained
Model picker and connector list render only when non-empty, so a misconfigured org shows a composer with controls simply missing — the exact failure that hid the pickers this morning. Show the control in a disabled state naming the org and what’s missing.
Compose
03
Agents is undiscoverable until someone opens Settings
The feature is GA, the toggle is off, and the tray gives no hint. Either default it on when the deployment reports Agents available, or put a single dismissible row in the tray that turns it on in place.
Discovery
04
Past prompts can’t be recalled
The SDK already fetches a chat’s prompt history; nothing calls it. Bind ↑/↓ on an empty composer to cycle it, as the web does — re-running a slightly edited prompt is the single most repeated action in this UI.
Compose
05
Four banner types stack above one transcript
Load error, stale context, retry and capacity each own a band. Two at once pushes the transcript down and none states a next action. Collapse to one status strip that shows the highest-severity condition with its action inline.
Recovery
06
No way to jump between chats from the keyboard
⌘N opens a new chat; there is no ⌘F into search and no jump-to-chat. For a window someone lives in all day, that’s the difference between glancing and hunting.
Triage
Deliberately not proposed: hard delete (the API archives only), a multi-org switcher UI (the org now resolves automatically — revisit if someone reports the wrong one), and live co-editing affordances.
