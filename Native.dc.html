Platform opportunities
What the Mac app can do that the web tab cannot
Agents supervision is background work: you start something, leave, and want to know the moment it needs you. That is exactly what macOS is good at — and where a browser tab is structurally worse. Today the app uses three of these well; the rest are unclaimed.
Already native
Menu-bar extra with live chat status · Notification Center banners on turn completion · Quick Look for attachments · system dictation in the composer · VoiceOver labels throughout
Spotlight finds your chats
HIGH
Donate every chat as a CSSearchableItem — title, last turn summary, workspace, status. ⌘Space from any app jumps straight into the chat. The framework is already linked; nothing is donated.
Dock badge & recent chats
HIGH
The unread count already exists per chat. Sum it onto the Dock tile so “something wants me” is visible without opening anything, and put the five most recent chats in the Dock’s right-click menu.
Menu bar commands & shortcuts
HIGH
There is no .commands block, so the app’s shortcuts are undocumented and unrebindable. A Chat menu makes them discoverable, searchable from Help, and customisable in System Settings.
Drag in, drag out
MED
Drop files onto the composer to attach; drag a transcript attachment or an exported diff back out to Finder or Mail. Paste already works — drag is the half a Mac user reaches for first.
Shortcuts & App Intents
MED
Expose “Start an agent on…” and “Latest agent status” as App Intents: usable from Shortcuts, the menu bar, Spotlight and Siri. This is how a supervision tool becomes scriptable without an API client.
A window per chat
MED
Supervising three agents means watching three transcripts. Let a chat open in its own window — with native window tabbing and state restoration, so a relaunch brings the same set back.
Notification actions
MED
Banners fire on turn completion but only open the chat. Add actions — Reply inline, View diff, Stop — so an answer to “should I proceed?” never needs the window. The interruption is already earned; make it productive.
Services menu
LOW
“Send to Coder Agent” on any selected text, anywhere in macOS — a stack trace in Console, a paragraph in Mail — opens a new chat pre-filled. Cheap to add, and it makes the app a system citizen.
If only three ship: Spotlight donation, the Dock badge, and the menu-bar commands. Together they mean a user can leave the app entirely, get pulled back only when it matters, and find their way around by the conventions they already know — none of which a browser tab can offer.
